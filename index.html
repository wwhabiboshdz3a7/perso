    Bonjour.
    Prenez la main sur l’écran.

    JARVIS lit vos gestes avec la caméra et écoute vos commandes vocales. Attrapez une photo d’un poing fermé sur un appareil, ouvrez la main devant un autre : elle y atterrit.

    • Tout reste sur votre appareil. L’image de la caméra est analysée localement et n’est jamais envoyée. Seule la photo que vous attrapez quitte l’appareil, en direct, vers les appareils que vous avez reliés.
    • Caméra : suivi des deux mains à 21 points, avec un modèle embarqué (pas de serveur).
    • Micro (facultatif) : dites « Jarvis » puis votre commande. Le clavier fonctionne aussi.

    Confidentialité : ce qui est traité, et où · Fonctionne mieux dans Chrome, Edge ou Safari récents, en HTTPS.

            Banc de simulation

            Rejoue des gestes à travers le même moteur que la caméra. La cible est la photo sélectionnée ou le centre.

            Gestes enregistrés

              Veille

              Dites « Jarvis, réveille-toi », levez la main ouverte une seconde, ou appuyez sur une touche.

              Réglages

              Calibration

              Mesure votre pincement et votre poing pour ajuster les seuils (caméra requise, 10 secondes).

              Cerveau IA désactivé

              Pour les questions libres, JARVIS peut interroger un modèle via une API compatible OpenAI (Groq, OpenRouter, Mistral, Ollama ou LM Studio en local…). La clé reste dans ce navigateur et n’est envoyée qu’au point d’accès choisi.

              Serveur de signalisation (PeerJS)

              Il sert uniquement à mettre les appareils en relation ; les photos passent ensuite en direct (WebRTC). Laissez vide pour le serveur public PeerJS.

              Les gestes

              1. 1Visez la photo avec l’index sur l’appareil A.
              2. 2Fermez le poing : la photo est dans votre main.
              3. 3Ouvrez la main devant la caméra de l’appareil B — ou lancez-la.

                Astuce : tenez la main à 40–80 cm de la caméra, paume vers l’écran, dans un endroit éclairé.

                Relier un appareil

                Scannez avec l’appareil photo du téléphone, ou saisissez le code dans la liaison de l’autre appareil.
