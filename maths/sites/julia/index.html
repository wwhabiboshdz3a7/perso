Approche

Ce qu'on voit derrière vous : une seule règle, répétée

Le fond de cette page est un ensemble de Julia : chaque pixel applique la même opération, z → z² + c, encore et encore, et on regarde s'il s'échappe ou s'il reste. Une règle minuscule, une structure infinie.

Les organisations fonctionnent pareil. Les règles de décision — accorder un crédit, réassortir un stock, prioriser un patient — s'appliquent des milliers de fois par jour. Les améliorer de quelques pour cent change tout. C'est notre métier : trouver la règle, la mesurer, l'industrialiser.

La formule

z → z² + c, et une palette en cosinus

L'image est calculée en temps réel sur votre carte graphique. Le paramètre c tourne lentement sur un cercle ; le zoom respire. Les couleurs viennent d'une formule de palette due à Inigo Quilez.

zn+1 = zn² + c        c = 0,7885 · eiθ
couleur(t) = a + b · cos( 2π (c·t + d) )

Pour chaque pixel, on compte combien d'itérations il faut pour que |z| dépasse 2. Ce nombre, lissé, devient t, puis une couleur. Réglez θ, le nombre d'itérations et le zoom ci-dessous ; le hero suit.
