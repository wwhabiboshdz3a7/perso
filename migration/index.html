Migration · anime.js · GSAP

Vous savez déjà animer

Kinetika reprend les idées qui ont fait leurs preuves : des cibles, des paramètres, des timelines. Cette page met les écritures côte à côte pour passer d’une librairie à l’autre sans réapprendre.

Trois différences à retenir

01 · temps

Millisecondes

Comme anime.js, toutes les durées sont en millisecondes. Depuis GSAP : duration: 1 devient duration: 1000, '+=0.5' devient '+=500'.

02 · positions

< et <<

Dans une timeline, '<' désigne la fin de l’élément précédent et '<<' son début. Le '<' de GSAP s’écrit donc '<<'.

03 · cibles

Premier argument

Les cibles sont toujours le premier argument : animate(cibles, paramètres) et tl.add(cibles, paramètres, position).

Depuis anime.js

Kinetika est très proche d’anime.js 4 (version actuelle : 4.5) : mêmes noms de paramètres, mêmes positions de timeline. Les écritures de la version 3 sont rappelées en second, car beaucoup de projets s’en servent encore.

anime.js 4
import { animate, stagger } from 'animejs';

animate('.carte', {
  x: 250,
  rotate: '1turn',
  delay: stagger(100),
  ease: 'outElastic(1, .6)',
  alternate: true,
  loop: true,
});
Kinetika
import { animate, stagger } from 'kinetika';

animate('.carte', {
  x: 250,
  rotate: '1turn',
  delay: stagger(100),
  ease: 'outElastic(1, .6)',
  alternate: true,
  loop: true,
});

Depuis anime.js 3 : anime({ targets: '.carte', translateX: 250, easing: 'easeOutElastic(1, .6)', direction: 'alternate' }) s’écrit comme ci-dessus. Kinetika accepte aussi translateX et les noms 'easeOutElastic', qu’il convertit.

Depuis GSAP

GSAP
const tl = gsap.timeline({ defaults: { duration: 0.8, ease: 'power3.out' } });
tl.from('.titre', { yPercent: 110 })
  .to('.photo', { scale: 1, autoAlpha: 1 }, '<')
  .to('.barre', { scaleX: 1, stagger: 0.08 }, '+=0.2')
  .addLabel('fin')
  .call(() => console.log('fini'), null, 'fin');
Kinetika
const tl = timeline({ defaults: { duration: 800, ease: 'outQuart' } });
tl.add('.titre', { y: { from: '110%' } })
  .add('.photo', { scale: 1, opacity: 1 }, '<<')
  .add('.barre', { scaleX: 1, delay: stagger(80) }, '+=200')
  .label('fin')
  .call(() => console.log('fini'), 'fin');

À noter : 'power3.out' fonctionne tel quel (il est converti en 'outQuart'), mais les durées et décalages doivent passer en millisecondes.
