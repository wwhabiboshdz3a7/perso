# Déposer un projet ici

Chaque dossier ou fichier `.zip` placé dans ce dossier `sites/` devient un site public :

    sites/mon-projet/      →  https://wwhabiboshdz3a7.github.io/perso/mon-projet/
    sites/autre-site.zip   →  https://wwhabiboshdz3a7.github.io/perso/autre-site/

Le projet doit contenir un fichier `index.html` à sa racine. Pour retirer un site, supprime son
dossier ou son zip. La liste des liens est sur https://wwhabiboshdz3a7.github.io/perso/
